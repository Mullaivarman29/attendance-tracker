
# Attendly - Student Attendance Tracker

A responsive attendance management website for 10 students.

## Features

- Mark students Present or Absent
- Select attendance dates
- Save daily attendance
- Edit student names
- View monthly attendance reports
- Calculate attendance percentages
- Export attendance as CSV
- Dark and Light themes
- Responsive mobile and desktop design

## Technologies

- HTML5
- CSS3
- JavaScript
- Browser LocalStorage
- GitHub Pages

## How to run

1. Download all four project files.
2. Keep them in the same folder.
3. Open index.html in your browser.

## GitHub Pages deployment

1. Create a GitHub repository.
2. Upload all four files.
3. Open Settings.
4. Select Pages.
5. Choose Deploy from a branch.
6. Select main branch.
7. Select / (root).
8. Click Save.

Your website will be published using GitHub Pages.

## Data storage

Attendance records are saved in the browser using LocalStorage.

Important:
- Data is stored on the current browser and device.
- It does not automatically synchronize between devices.
- Export CSV backups regularly.
- Clearing browser data can erase saved attendance.

GitHub Pages does not provide a database.
